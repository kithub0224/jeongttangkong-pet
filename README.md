# 🥜 정땅콩 데스크톱 펫

컴퓨터 화면 아래, 작업 표시줄(맥은 Dock) 위에서 정땅콩을 키워 보세요!

## 다운로드

오른쪽 **Releases**에서 최신 버전을 받으세요.

| 컴퓨터 | 받을 파일 |
|---|---|
| 윈도우 | `jeongttangkong.exe` |
| 맥 (M1 이후 애플 실리콘) | `jeongttangkong-mac.zip` |

### 윈도우에서 실행
1. `jeongttangkong.exe`를 더블클릭해요.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.
   (개인이 만든 무료 프로그램이라 인증서가 없어서 뜨는 창이에요)

### 맥에서 실행
1. `jeongttangkong-mac.zip`을 더블클릭해 압축을 풀고, `jeongttangkong` 앱을 응용 프로그램 폴더로 옮겨요.
2. 앱을 **오른쪽 클릭 → 열기 → 열기**로 실행해요.
3. 그래도 안 열리면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽에서 **그래도 열기**를 눌러요.

## 노는 법
- 작업 표시줄 위를 걷고, 뛰고, 뒹굴고, 인사하고, 쉬어요.
- 마우스를 움직이면 커서 쪽을 쳐다봐요.
- 클릭 1번·2번·4번: 하트 / 빠르게 3번: 점프 / 빠르게 5번: 화내기
- 끌어서 옮기면 놓았을 때 작업 표시줄로 떨어져요.
- 1분 동안 마우스를 안 움직이면 졸다가 잠들어요. 자는 동안 옮기면 깨서 화내요!
- 오른쪽 클릭(맥은 control+클릭) 메뉴: 동작 시키기, 크기(작게·보통·크게·거대하게), 종료

## 컴퓨터 켤 때 자동 실행 (선택)
- 윈도우: `Win + R` → `shell:startup` → 열린 폴더에 exe 바로 가기 넣기
- 맥: 시스템 설정 → 일반 → 로그인 항목 → `+`로 앱 추가
